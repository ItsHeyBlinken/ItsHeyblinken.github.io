# Product context

## Audience

Local contractors and service-based businesses that need a professional website without managing it themselves. Messaging: **You run the business. We handle the website.** Primary offer is Website Starter ($250 setup + $50/month).

## Positioning

- Agency-style presentation (BytesByBlinken Media) with a single Website Starter offer plus a template catalog. SEO, referrals, and higher monthly packages are later phases—do not sell a multi-tier package menu yet.
- Athlete recruiting profiles are archived (files remain, not linked or indexed). Do not promote them on public pages.
- Contact flow: **email first** → response SLA messaging → call for details when appropriate.

## Key surfaces

| Page | Role |
|------|------|
| Home | Value proposition, trust, CTAs, FAQ-style content as designed |
| Templates | Filterable or browsable template gallery; links to demo sites under `Site Templates/` |
| Pricing | Website Starter offer ($250 + $50/month) |

## Content and compliance

- Google Analytics via gtag (ID present in HTML).
- `google-site-verification` meta where configured.
